# Circuit Breaker + Twin Tower (Pine v6)\n\nThis indicator draws market-specific circuit breaker (CB) levels and optional Twin Tower structures per settlement period.\n\nFeatures:\n- Market presets: CRYPTO, INDICES, FOREX\n- Settlement-aware drawing from settlement to settlement\n- Main CB levels, decimated CB levels, and mid-levels\n- Crypto-specific 10% and 1% increment levels with optional mid-lines\n- Twin Tower and Twin Tower Mini levels, optional shaded fills\n- Adjustable historical periods to display\n\nMain file: `circuit-breaker.pine`\n\n## Quick Start\n1. Open TradingView Pine Editor.\n2. Paste `circuit-breaker.pine` and add to chart.\n3. Choose market (CRYPTO/INDICES/FOREX) and toggle desired levels.\n\n## Notes\n- Fills can be limited to the current period for consistent opacity.\n- Fix price can be set manually or auto-derived (previous daily close by default).\n\n## License\nChoose and add a license if publishing.\n
